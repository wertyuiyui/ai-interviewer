# Repository agent instructions

Before changing any file in this repository, read and follow `process.md`.

- Register the task and intended files in `process.md` before editing.
- Record every logical code, configuration, data, test, documentation, or deployment change in `process.md` before declaring completion.
- Coordinate overlapping file ownership with the primary Agent; never silently overwrite another Agent's active work.
- Do not place secrets, private user content, or raw uploaded project material in the shared ledger.
- Sub-agents must not stage, commit, push, or deploy unless the primary Agent explicitly delegates that action.
